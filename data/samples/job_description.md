# Senior Software Engineer — Backend (Payments Platform)

**Company:** FinFlow Inc. · **Location:** Remote / Hybrid · **Level:** Senior (5+ years)

## About the role
FinFlow processes millions of payment transactions daily for small businesses. We're looking for a Senior Backend Engineer to design and scale the core payments platform: transaction processing, ledgering, and payouts.

## Responsibilities
- Design, build, and operate highly available, low-latency backend services in **Java** (Spring Boot) and **Python**.
- Own services end to end: architecture, implementation, testing, deployment, on-call.
- Design data models for financial correctness (idempotency, exactly-once semantics, reconciliation).
- Scale event-driven systems using **Kafka** and distributed caches.
- Lead technical design reviews and mentor engineers.
- Partner with product and compliance teams on new payment features.

## Must have
- 5+ years of professional backend development experience
- Strong Java and/or Python skills
- Distributed systems design: consistency, partitioning, retries, idempotency
- Relational databases (PostgreSQL) and query optimisation
- Event streaming (Kafka or similar)
- Cloud experience (AWS preferred), Docker, Kubernetes

## Nice to have
- Payments, fintech, or ledger systems experience
- Experience with PCI-DSS or other compliance requirements
- Observability tooling (Prometheus, Grafana, OpenTelemetry)
- Open-source contributions

## Interview process
Recruiter screen → technical phone screen (coding) → onsite: coding, system design, behavioral, hiring manager.
